# v2.31.0 端侧小模型与智能体可信执行

## 一、智能体行为

- 系统提示已移除「与账本无关即禁止调用工具」等一刀切约束；是否调工具由模型自主裁决。
- 完成凭据只能来自真实落库回执：`【账本已核验】` + `rows_affected>0`。
- 回归用例：`AgentV2310Test`（提示词、回执契约、连续落库、金额不臆测）。

## 二、执行授权

路径：**设置 → AI 辅助设置 → 智能体执行授权**

| 档位 | 行为 |
|------|------|
| 每次执行前需确认（默认） | 写工具返回确认卡片，点「确认执行」才落库 |
| 授权后自动执行 | 写工具直接落库，金额/时刻未明示仍先追问 |

## 三、会话续接

- 退出再进自动恢复最近会话（`last_conversation_id`）。
- AI 管家左上角菜单：会话列表（切换 / 新建 / 删除）。

## 四、端侧小模型

路径：**设置 → 端侧小模型（免费离线）** 或 **AI 设置 → 端侧小模型 → 管理端侧模型**

1. 启动探测内存 / SoC / 档位，推荐 0.6B–1.5B 量化包。
2. 下载：直连、断点续传、指数退避、磁盘预检、完整性校验。
3. 推理路由：GPU（MNN/Vulkan 位）→ CPU（GGUF 位）→ 内置精简规划器（保证离线可记账/查账）。
4. 「跑基准」查看 tok/s 与首字延迟后再启用。
5. 启用后将「智能体大脑」切到端侧；飞行模式可用，数据不出设备。

> 正式 GGUF 权重 URL 可在 `OnDeviceModelCatalog` 中替换；当前内置规划器保证无原生 .so 时链路仍可执行。

## 五、二级分类贯通 + 高级分析

- 统计饼图 / 结构演进 / 类目弹性 / 桑基 / 雷达 / 体检排行：有二级时按「一级/二级」维度，无二级退回一级。
- 频次曲线、结构演进、环比水位、商户集中度、类目弹性、帕累托累计 → 统计页底部「高级分析」展开区，默认折叠。

## 六、分类管理就地化

- 记一笔 / 编辑页：「管理」打开底栏，可增删改一级与二级，无需跳转设置。

## 七、首页密集风

- 信息密集版式：近 7 日热力柱、高频商户 Top、类目占比速览（二级维度），替换纯数字填充。

## 八、收支口径 + 预算测算

- 路径：**设置 → 收支口径（退款/投资）**
- 开关：退款 / 投资分红 / 投资支出是否计入统计与预算（默认计入）。
- 月底预估：日频（地铁/餐饮等）按日均外推；一次性/低频（话费、火车票等）只计一次，不摊销。

## 九、无感记账

- 总开关 + 通知监听授权；包名白名单（微信/支付宝/云闪付/钱包）。
- 60 秒 + 当天同金额同商家去重（支付通知与到账通知合并）。
- 低置信或「每次确认」执行授权 → `SOURCE_DRAFT` 草稿，不进统计；确认后升为 `SOURCE_AUTO`。
- 本地-only：通知正文本机解析，不上传、不读短信。
