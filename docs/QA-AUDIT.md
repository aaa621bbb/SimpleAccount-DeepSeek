## 2. 异常路径

| 场景 | 处理 |
| --- | --- |
| 金额空 / 未选分类 / 日期非法 | ViewModel 设 `error`，不关闭页 |
| 筛选无结果 | EmptyState 提示交叉筛选，可清除 |
| 撤回不存在的流水号 | 本地回「不在账本里」 |
| 识图未配 Key | 明确去设置，不空转 |
| 识图 | 一次请求；主模型失败才回退，禁止第三次 |
| 异常日 | 仅当天 > 日均×2.2 且 >80 元才出 |
| 超额 | 未设预算不出超额块，禁止无据预警 |
| 批量改分类无 ids | 预览拒绝；匹配 >30 笔要求先查流水号 |
| 闲聊 | 不扫账本、不调 query_transactions |
| 开思考 | thinking_budget / reasoning_effort 封顶，读超时 75s，不是分钟级空转 |

## 3. 状态一致

- 选择器风格：默认 `date_wheel` / `time_dial`。
- 筛选：空 Set = 该维全部；type 仍单值。
- 体检数字：只读当前账本本月流水；无固定块。
- 思考档位：设置页四档，运行时按用户选择。
- 统计新模块追加到 `DEFAULT_ORDER` 末尾，旧顺序设置仍有效。

## 4. 泄漏

- 同 2.24：监听、保活、ContentObserver 随生命周期取消。
- 商家联想 Flow `WhileSubscribed(5_000)`。

## 5. 无障碍

- 表盘、胶片日、拍账单、上传账单有描述。
- 减弱动态：时长/过渡为 0 时全部 snap，页转场瞬时。
- 风险/超额文案写规则，不把信息只放在颜色里。

## 6. 帧率 / 内存

- 动效只改 transform/opacity。
- 流式滚动用 `scrollToItem`，不每 40 字 `animateScrollToItem` 打断下探。
- 账本仍逐条懒加载，月卡不整月全渲染。
- 目标 60fps，剧烈 ≥45fps。真机需 Systrace。

## 7. 否决项核对

- 未用换配色充当本轮重构。
- 未把日历栅格作为默认日期方案。
- 未把订阅雷达放进风险；「固定」已下架。
- 未对管家撤回走长时间思考或「无法执行」。
- 日期+时间合计 12 套（≥10），2.18 圆盘仍为时间默认。
- 账本筛选非单值互斥。
- 统计新视角非清一色条形。
- 未再强制关闭思考。
- 体检有对照/漂移/超额/周期/动作，否则本月空账不占导航。
- 管家可对某商户下选定若干笔改分类。
- 无关 query 不打账本库。
- 流式不强制回卷首行。
- 推理链不逐词换行碎裂。
- 账本行有卡片级层级，非扁平清单。

## 结论

静态全量审查通过，第二补充批次已知问题已闭环。版本 **2.25.0 / 42** 作为本轮稳定版提交到当前工作分支。真机：表盘手势、OEM 杀后台、识图一次成功率、开思考首 token、流式长回复下探仍建议实装验证。
