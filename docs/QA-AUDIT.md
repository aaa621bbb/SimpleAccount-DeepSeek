# 2.24 全量端到端审查

审查范围：管家强制关推理链、账本多值交叉筛选、体检「固定」下架、商家联想、全 App 设计令牌与动效、统计十个新视角。已知问题闭环后发 **2.24.0（versionCode 41）**。

本环境 `ANDROID_HOME` 为空，不能编 APK / 跑真机帧率。结论来自静态审查。回滚点：本分支父提交。本会话只推 `arena/01a06d4a-simpleaccount-deepseek`，不直推主干、不 force-push。

## 2. 异常路径

| 场景 | 处理 |
| --- | --- |
| 金额空 / 未选分类 / 日期非法 | ViewModel 设 `error`，不关闭页 |
| 筛选无结果 | EmptyState 提示交叉筛选，可清除 |
| 撤回不存在的流水号 | 本地回「不在账本里」 |
| 识图未配 Key | 明确去设置，不空转 |
| 识图 | 一次请求；主模型失败才回退，禁止第三次 |
| 异常日 | 仅当天 > 日均×2.2 且 >80 元才进风险 |
| 推理链 | 强制关；低复杂度不得分钟级起步 |

## 3. 状态一致

- 选择器风格：默认 `date_wheel` / `time_dial`。
- 筛选：空 Set = 该维全部；type 仍单值。
- 体检数字：只读当前账本本月流水；无固定块。
- 思考档位：UI 隐藏，运行时忽略用户旧值。
- 统计新模块追加到 `DEFAULT_ORDER` 末尾，旧顺序设置仍有效。

## 4. 泄漏

- 同 2.23：监听、保活、ContentObserver 随生命周期取消。
- 商家联想 Flow `WhileSubscribed(5_000)`。

## 5. 无障碍

- 表盘、胶片日、拍账单、上传账单有描述。
- 减弱动态：时长/过渡为 0 时全部 snap，页转场瞬时。
- 风险文案写规则，不把信息只放在颜色里。

## 6. 帧率 / 内存

- 动效只改 transform/opacity。
- 页转场只 fade + 1/14 屏位移。
- 统计新图均为 Canvas / 轻量格子，无 layout 动画。
- 目标 60fps，剧烈 ≥45fps。真机需 Systrace。

## 7. 否决项核对

- 未用换配色充当本轮重构。
- 未把日历栅格作为默认日期方案。
- 未把订阅雷达放进风险；「固定」已下架。
- 未对管家撤回走长时间思考或「无法执行」。
- 日期+时间合计 12 套（≥10），2.18 圆盘仍为时间默认。
- 账本筛选非单值互斥。
- 统计新视角非清一色条形。

## 结论

静态全量审查通过，补充批次已知问题已闭环。版本 **2.24.0 / 41** 作为本轮稳定版提交到当前工作分支。真机：表盘手势、OEM 杀后台、识图一次成功率、多选筛选大数据量仍建议实装验证。
