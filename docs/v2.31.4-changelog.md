# v2.31.4 变更摘要

## 一、统计「仅二级」去掉一级层
- 二级全拆时饼图/图例只保留二级（及「一级/未细分」叶子），不再与一级汇总并行，避免双重归属。
- 合并模式仍为一级 + 可展开下钻二级。

## 二、端侧模型跨版本持久化
- 下载/导入均写 `*.meta.json` sidecar；启动 `restoreImported` + 漂移恢复 + 磁盘 `.bin` 残留扫描。
- 残留项可启用或「清理残留」；「查看文件列表」定位私有目录路径。
- `activeModelFile` 兼容 filePath 与 id.bin。

## 三、批量商家归类
- 新增 `suggest_merchant_categories`（建议不落库）+ 增强 `classify_merchants`（映射+追改账单，rows_affected）。
- Prompt / IntentGate / pickTools 禁止「数量太多/没有工具」推脱。

## 四、规则记账
- KeywordRules 扩词表 + 最长关键词优先；UtteranceParser 扩意图/商家后缀。

## 五、月底约入口
- 首页点击改为页内 BottomSheet 测算摘要，避免 navigate 崩溃；可选再进详情页。
