## 3. 写路径与授权

- `WriteGate` 13 项写工具；`confirmed=false` 只预览。
- `AgentLoop`：`autoExecute = isAgentAutoExecute()`；云端仍要求 AI 开 + Key；端侧可跳过 Key。
- 无感记账：总开关 + 监听权限；confirm 或低置信 → 草稿；与 AI 共用 exec-auth。
- 回执契约：`【账本已核验】` + `rows_affected>0`；伪造不可核验。

## 4. 生命周期 / 资源

- `SimpleAccountApp`：`SupervisorJob` IO scope；启动灌预置分类/二级、账本默认、无感 pipeline、日频 retention。
- `onTrimMemory` 清日志环。
- 无感：`NotificationListener` + `KeepAliveService(dataSync)` + `BootReceiver`（含 MY_PACKAGE_REPLACED）。
- 端侧：native 位恒 false → 内置规划器；下载可取消、sha256、断点。

## 5. 性能 / 内存

- 首页 / 统计 / 账本：`flowOn(Default)` 聚合。
- 统计大账本避免主线程卡顿；账本 filter debounce 160ms。
- 已知：`SettingsRepository.readSetting` 使用 `runBlocking`（历史设计，主线程偶发 IO 风险，未在本版扩大调用面）。

## 6. 已知非阻断项（接受并记录）

1. **无 JDK 环境**：本沙箱无法 `./gradlew assembleDebug`；发布方须在 CI/本机完成编译与单测。  
2. **端侧无原生 .so**：文档已声明；内置规划器保底，非生产 GPU 推理。  
3. **release minifyEnabled=false**：与历史一致；签名与 debug 共用便于覆盖安装。  
4. **lint abortOnError=false**：历史配置；不作为本版回归门禁。  
5. **`exportSchema=false`**：无 schema 产物目录；迁移靠手写 Migration 链。  
6. **图标占位**：README 已知，非功能阻断。
