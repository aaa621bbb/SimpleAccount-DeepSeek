# v2.31.1 变更摘要

## 一、记账识别引擎五档（互斥）

设置 → AI 服务商 → **记账识别引擎**：

| 模式 | 行为 |
|------|------|
| 纯 API | 仅云端 Agent |
| 纯端侧 | 仅本地小模型 |
| 纯规则 | 仅 LocalAccountant / UtteranceParser |
| API × 规则 | 规则先吃，吃不准再 API（默认兼容） |
| 端侧 × 规则 | 规则先吃，吃不准再端侧 |

切换即时写 Settings 并同步 `model_backend`；同一次输入只走一条路径，禁止双引擎抢答。

## 二、端侧下载 / 导入

- OkHttp 直连 HF/源站，**不经业务 API / 断网开关**。
- 模型卡片展示：名称、简介、参数量、量化、体积、预估吞吐。
- **从本机导入** GGUF/bin：复制注册 + sidecar 元数据，可启用/删除。

## 三、意图：高置信消费 → 记账

例：「今天上午9:25在蜜雪冰城买了个雪糕」

- `IntentGate.isHighConfidenceSpend`：时间 + 消费动词/商户（金额可缺）→ `LEDGER_WRITE`
- 排除「花了多少」查询
- `LocalAccountant.tryProposeWrite` 接住并**追问金额**（不降级闲聊、不臆测）

## 四、分类就地 CRUD + 月底测算详情

- 记一笔页「管理」→ 一级/二级增删改，不跳设置。
- 首页「月底约 / 预计月底」可点 → **测算详情**（公式、口径豁免、一次性 vs 日频聚类）。

## 五、推理耗时与落库凭据

- Agent 回复脚注总耗时（推理+工具轮次）。
- 写操作仍以 `rows_affected` / `【账本已核验】` 为唯一成凭；sanitize 拦截 fake-complete。

## 六、进 AI 管家默认新会话

- `AiViewModel.init` → `newConversation()`，欢迎语不再写「续接」。
- 历史会话仍在左上角列表可切换。
