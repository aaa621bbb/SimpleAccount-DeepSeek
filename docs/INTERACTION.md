# 可评审交互规范（2.22）

配套 `docs/MOTION.md`。本文写「用户怎么走完一条路」，不写配色。换皮肤不算本轮交付。

## 1. 记一笔

1. 首页 FAB → 记一笔。金额、分类、日期、时间、商家/商品同屏。
2. 点日期：按「我的 → 日期与时间选择器」当前日期风格弹出（默认滚轮鼓，另有胶片 / 叠卡）。**不用系统日历栅格。**
3. 点时间：按当前时间风格（默认圆盘表，另有弧轨 / 翻页）。圆盘外圈点到即设分，内圈改时；拖中整分磁吸，松手回弹。
4. 底栏保存，首屏零滚动可达。金额空 / 未选分类 / 日期非法：页内报错，不关页。
5. 编辑记录复用同一屏（`edit/{id}`）。

验收：三种日期 × 三种时间都能把值写回 `yyyy-MM-dd` / `HH:mm`；减弱动态时无弹簧、无触觉。

## 2. 本月体检

1. 首页顶部数值主卡：本月支出（最大字号）+ 结余 + 预算。
2. 其下「本月体检」卡：等级字母 + 分数 + 一句可由账本推出的摘要。点开弹层。
3. 弹层按 **总览 / 结构 / 节奏 / 固定 / 风险 / 建议** 分块。每条有 title（数字）和 body（规则）。点一条列出对应流水。
4. **禁止**：订阅进风险；无依据的「异常」；晦涩术语。异常日仅当「当天 > 日均 × 2.2 且超过 80 元」。固定支出单独成块。

## 3. 管家闭环

| 用户说 | 路径 | 期望 |
| --- | --- | --- |
| 「帮我记 星巴克 15 元」 | 本地会计 `parseAdd` | 立刻入账并回报流水号 |
| 「撤回 12」/「撤回一笔」 | 本地会计 `parseWithdraw` | 立刻删对应或最新一笔，不思考 |
| 分析 / 怎么办 / 体检 | 模型 + 工具 | 数字来自快照或 `get_insights` |
| 拍账单 | 首页相机 / 管家相册 / 无感页「一键选图」 | 一次请求识图，最多主模型失败再回退一次 |

流式：段内换行并成空格，禁止把「一千二百」拆成逐词换行。记忆：设置 → 管家记忆，按日 Markdown 可查。

## 4. 首页信息架构

从上到下：账本名 | 拍账单+上传账单 → 压缩后的本月支出卡 →（可选）重复记账条 → 体检卡 → 再记一笔芯片 → **最近记录（占剩余 ≥ 半屏）**。列表 `weight(1f)`，默认最多 30 条。

## 5. 无感记账

设置页顶部三步图文：开开关 → 授权通知 → 忽略电池优化。付一笔后看首页最近记录。小米/华为不关电池优化 = 记不上，文案写明。一键拍账单跳管家识图，不在本页反复调模型。

## 6. 统计新口径（不重复）

| 模块 | 说什么 | 不说什么 |
| --- | --- | --- |
| 饼 | 本月分类构成 | 走势 |
| 折 | 近 12 月走势 | 单月高低对比 |
| 柱 | 近 12 月收支高低对照 | 构成 |
| 星期 | 按账单日期的星期几合计 | 「你周末更浪」的猜测 |
| 时段 | 按账单时刻五档 | 没填时间的账 |

顺序/显隐：我的 → 统计页图表。

## 7. 设置开关

- 日期风格、时间风格：分别三项，互不影响。
- 外观与配色：独立页，**本轮不以换色充重构**。
- 管家记忆：按日查看，不提供密钥写入。

## 8. 无障碍与稳健

- 表盘、胶片日、拍账单、上传账单有 `contentDescription`。
- 减弱动态：全部瞬时到位。
- 密度/横竖屏/IME：dp + `adjustResize` + `imePadding`。不因旋转丢 ViewModel。
