# 可评审交互规范（2.29）

配套 `docs/MOTION.md`。本文写「用户怎么走完一条路」，不写配色。三套皮肤是结构（玻璃/景深/平面），不是换色。

## 1. 记一笔

1. 首页 FAB → 记一笔。金额、分类、日期、时间、商家/商品同屏。
2. 点日期：按「我的 → 日期与时间选择器」当前日期风格弹出（默认滚轮鼓；另有胶片 / 叠卡 / 时间轴 / 算盘珠 / 地平 / 扇骨 / 螺线 / 三柱 / 罗盘 / 账页，共 11 套）。**不用系统日历栅格。**
3. 点时间：按当前时间风格（默认 **机械表盘**；另有弧轨 / 翻页 / 双柱 / 双环 / 直尺 / 沙漏 / 双鼓 / 日晷 / 节拍器 / 积木，共 11 套）。不用版本号当样式名。
4. 商家框：已建档商家前缀优先、其次包含联想，点选回填。相近店名不会被合成一家。
5. 底栏保存，首屏零滚动可达。金额空 / 未选分类 / 日期非法：页内报错，不关页。
6. 编辑记录复用同一屏（`edit/{id}`）。

验收：十一种日期 × 十一种时间都能把值写回 `yyyy-MM-dd` / `HH:mm`；设置页可当场预览、打开完整选择器；减弱动态时无弹簧、无触觉。

## 2. 本月体检

1. 首页顶部数值主卡：本月支出（最大字号）+ 结余 + 预算。
2. 其下「本月体检」卡：一句可决策标题（超预算/环比/最大头）+ 同期对照副文。本月无账则整卡不出现。
3. 弹层按 **对照 / 漂移 / 超额 / 周期 / 动作** 分块。每条有数字和规则。点一条列出对应流水。
4. **禁止**：订阅进风险；无依据的「异常」；晦涩术语；「固定」口径；「账记得挺稳」。未设预算不出超额。

## 3. 管家闭环

| 用户说 | 路径 | 期望 |
| --- | --- | --- |
| 「帮我记 星巴克 15 元」 | 本地会计 `parseAdd` | 立刻入账并回报流水号 |
| 「撤回 12」/「撤回一笔账单」 | 本地会计 `parseWithdraw` | 立刻删对应或最新一笔，不思考、不二次确认 |
| 「把流水号 12 改成餐饮」 | 本地会计 `parseRecategorize` | 对象级改分类；商家最多 800 笔一次改；回执带 `rows_affected` |
| 「打开无感记账」 | 本地会计 `parseAutoRecord` | 立刻开开关并提示去授权 |
| 分析 / 怎么办 / 体检 | 模型 + 工具 | 数字来自快照或 `get_insights`；尊重用户思考档 |
| 拍账单 | 首页相机 / 管家相册 | `max_tokens≤1024`；相对时间解析成 HH:mm |

写工具执行完立刻把工具结果当最终答复，并带【账本已核验】`rows_affected=N`。`N=0` 报失败。思考深度用户自选（关/低/中/高）。**写账回合对非刚需模型关思考，不改设置档**；GLM 4.5/4.6 等刚需模型即使写账也保持思考开启，且只发 `thinking.type=enabled`，不发 `enable_thinking=false`。已开启不得再提示「需开启思考模式」。`query_transactions` 最大 500。思考链默认折叠。识图预览禁止「时间未知」。

商家归类：候选 = 预置 ∪ 自建（按名去重，库优先）。Sheet 可滚、按支出/收入 × 预置/自建分组。工具描述禁止写死内置十类。

## 4. 首页信息架构

从上到下：账本名 | 拍账单+上传账单 → 压缩后的本月支出卡 →（可选）重复记账条 →（可选）导入差缺/待归类纠错条 → 体检卡 → **最近记录（占剩余 ≥ 半屏）**。

**禁止**「再记一笔」芯片。空列表走 EmptyState。

## 5. 账本筛选

月份 Chip、分类 Chip 都是多选。维内并集、维间交集。搜索框 caret 不回跳。行：商家主标题、分类次级、金额强调。皮肤下沉到列表条。

## 6. 无感记账

设置页顶部三步图文：开开关 → 授权通知 → 忽略电池优化。

## 7. 统计视角（互斥）

十个互斥视角（频次/结构演进/环比水位/集中度/弹性/帕累托/热力/火花/流向/雷达）。顺序：我的 → 统计页图表。**长按把手拖到落点**；落点有分隔预览；拖出列表回滚原位。箭头「上/下」留给无障碍。

## 8. 设置分组

外观（皮肤 / 配色 / 选择器 / 统计图表）· 管家（记忆 / AI）· 账本（账本 / 分类 / 商家 / 无感）· 数据（导出 / 日志 / 关于）。

- 皮肤三套：现行默认 / 液态玻璃 / 景深立体。切完立刻作用到卡片、按钮、输入、列表条。深浅色都成立。
- 日期 11、时间 11。时间默认「机械表盘」。设置页顶部可拖表盘、可打开完整选择器。
- 日志：级别 / 时间 / 正文分栏，可按 D/I/W/E 筛选，一键导出。
- 关于：版本、versionCode、GPL-3、用法、反馈（日志导出）。
- 管家记忆：按日点进，`##` 逐条可读。

## 9. 无障碍与稳健

- 表盘、胶片日、拍账单、上传账单、拖拽把手有 `contentDescription`。
- 减弱动态：全部瞬时到位。
- 密度/横竖屏/IME：dp + `adjustResize` + `imePadding`。
- 空态、加载、深浅色、三套皮肤走同一套 Tokens。
