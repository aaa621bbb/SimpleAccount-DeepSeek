# 可评审交互规范（2.28）

配套 `docs/MOTION.md`。本文写「用户怎么走完一条路」，不写配色。换皮肤不算本轮交付。

## 1. 记一笔

1. 首页 FAB → 记一笔。金额、分类、日期、时间、商家/商品同屏。
2. 点日期：按「我的 → 日期与时间选择器」当前日期风格弹出（默认滚轮鼓；另有胶片 / 叠卡 / 时间轴 / 算盘珠 / 地平，共 6 套）。**不用系统日历栅格。**
3. 点时间：按当前时间风格（默认 **2.18 圆盘**；另有弧轨 / 翻页 / 双柱 / 双环 / 直尺，共 6 套）。
4. 商家框：已建档商家前缀优先、其次包含联想，点选回填。相近店名不会被合成一家。
5. 底栏保存，首屏零滚动可达。金额空 / 未选分类 / 日期非法：页内报错，不关页。
6. 编辑记录复用同一屏（`edit/{id}`）。

验收：六种日期 × 六种时间都能把值写回 `yyyy-MM-dd` / `HH:mm`；减弱动态时无弹簧、无触觉。

## 2. 本月体检

1. 首页顶部数值主卡：本月支出（最大字号）+ 结余 + 预算。
2. 其下「本月体检」卡：一句可决策标题（超预算/环比/最大头）+ 同期对照副文。本月无账则整卡不出现。
3. 弹层按 **对照 / 漂移 / 超额 / 周期 / 动作** 分块。每条有数字和规则。点一条列出对应流水。
4. **禁止**：订阅进风险；无依据的「异常」；晦涩术语；「固定」口径；「账记得挺稳」。未设预算不出超额。

## 3. 管家闭环

| 用户说 | 路径 | 期望 |
| --- | --- | --- |
| 「帮我记 星巴克 15 元」「记一笔星巴克15」「帮我记星巴克15」 | 本地会计 `parseAdd` | 立刻入账并回报流水号；金额认 元/块/¥/记场景裸数字 |
| 「撤回 12」/「撤回一笔账单」 | 本地会计 `parseWithdraw` | 立刻删对应或最新一笔，不思考、不二次确认 |
| 「把流水号 12 改成餐饮」「把刚才那笔改成交通」「把星巴克全部改成餐饮」 | 本地会计 `parseRecategorize` | 对象级改分类；商家最多 800 笔一次改；回执带 `rows_affected` |
| 「把天津职业技术师范大学的五十元归类为居住，其余改成餐饮」 | 本地会计金额子集 + 其余 | 立刻写库并回读核验；不能解析则明说账本没改，禁止口头已完成 |
| 「打开无感记账」 | 本地会计 `parseAutoRecord` | 立刻开开关并提示去授权 |
| 分析 / 怎么办 / 体检 | 模型 + 工具 | 数字来自快照或 `get_insights`；尊重用户思考档 |
| 拍账单 | 首页相机 / 管家相册 / 无感页「一键选图」 | `max_tokens≤1024`；遇 GLM 1210 降到 1024 再试一次；最多主模型失败再回退一次 |

写工具执行完立刻把工具结果当最终答复，并带【账本已核验】`rows_affected=N`。`N=0` 报失败，禁止假完成。思考深度用户自选（关/低/中/高）；**写账回合强制关思考，不改设置里的档位**。写意图空工具先强制再调；仍空则「账本没有改动」。`query_transactions` 最大 500。思考链默认折叠，点「思考过程」只展开这一条。发图会清掉上一回合的思考缓存。流式贴底跟随，用户上滑下探不被拉回首行。识图须解析上午/下午/晚上/今天/昨天/前天，预览禁止「时间未知」。

## 4. 首页信息架构

从上到下：账本名 | 拍账单+上传账单 → 压缩后的本月支出卡 →（可选）重复记账条（点进账本）→（可选）导入差缺/待归类纠错条 → 体检卡 → **最近记录（占剩余 ≥ 半屏）**。

**禁止**「再记一笔」芯片：导入落库后再克隆同商户同金额，和已导入数据重复、流程自相矛盾。差缺条：失败条数 → 导入页核对；待归类商家 → 商家管理。空列表走 EmptyState。

## 5. 账本筛选

月份 Chip、分类 Chip 都是多选。同一维度内取并集，维度之间取交集。例：六月+八月 且 餐饮+交通。类型仍是全部/支出/收入。空集 = 该维全部。有筛选时列表下可「清除筛选」。

搜索框：键入立刻反映在输入框（caret 不回跳到本次键入之前）。列表按 debounce 160ms 过滤，避免每字全表扫描。

列表按月分组：月横幅含笔数与支出合计；日期变化出日分隔；行内商家为主标题、分类次级、金额强调、左侧类目色条。与首页最近记录同一信息层级。

## 6. 无感记账

设置页顶部三步图文：开开关 → 授权通知 → 忽略电池优化。付一笔后看首页最近记录。

## 7. 统计视角（互斥）

旧口径：饼=构成，折=走势，柱=高低对照，星期=星期合计，时段=五档时刻，日历=格子，商家=排行，对照=日均数字。

新十个：频次曲线、结构演进、环比水位、商户集中度、类目弹性、帕累托、星期×时段热力、日火花、收支流向、结构雷达。顺序/显隐：我的 → 统计页图表。

## 8. 设置分组

外观（配色 / 选择器 / 统计图表）· 管家（记忆 / AI）· 账本（账本 / 分类 / 商家 / 无感）· 数据（导出 / 日志 / 关于）。

日期风格、时间风格分别六项。时间默认「2.18 圆盘」。外观与配色独立页，**不以换色充重构**。

## 9. 无障碍与稳健

- 表盘、胶片日、拍账单、上传账单有 `contentDescription`。
- 减弱动态：全部瞬时到位；页转场时长归零。
- 密度/横竖屏/IME：dp + `adjustResize` + `imePadding`。不因旋转丢 ViewModel。
- 空态、加载、聚焦（商家栏 scale）、深浅色走同一套 Tokens。
