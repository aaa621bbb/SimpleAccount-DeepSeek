# v2.31.2 变更摘要（智能体边界 · 统计下钻 · 体验加固）

在 v2.31.1 之上，对齐「智能体能力边界与统计下钻」七项。

## 1. 对象级批量归类（金额阈值 / 区间）

- `reclassify_transactions` 支持 `amount` / `amount_lt` / `amount_lte` / `amount_gt` / `amount_gte`（元）+ `merchant` / `ids` / `from_category` / 日期 + 可选二级。
- 典型「企鹅」：先 `<0.5 → 餐饮`，再 `≥0.5 → 居住`，以 `rows_affected` 为成凭。
- Prompt / CHAT 工具集：禁止「只能跳手动页」；`IntentGate` 识别按金额/商家批量归类 → `LEDGER_WRITE`。

## 2. 端侧模型下载更稳

- `OnDeviceModelCatalog`：`mirrorUrls` + `allDownloadUrls()`（hf-mirror 优先，含 huggingface / ghproxy）。
- `OnDeviceModelManager.download`：多镜像外层轮询、单源重试、更长超时、UA、4xx 换源、HTML/过小文件拒绝、失败文案更明确。

## 3. 统计饼图：一级占比 → 展开二级 → 流水

- `PieSlice.children`：一级聚合 + 二级子扇区。
- 图例 `›/˅` 展开二级；点选一级/二级进入该类流水（`catTx` 双键）。

## 4. 首页「月底约」防崩

- `ProjectionDetailViewModel.load`：`runCatching` + 空 breakdown / 公式错误文案，避免测算详情硬崩。

## 5. 账本筛选：点选即用 · 二级粒度

- `LedgerFilter.matchesCategory`：支持 `一级` 与 `一级/二级`。
- 多月 / 多分类 Sheet 点选即时 `onConfirm`（80ms 防抖）；分类 Sheet 可展开二级。

## 6. 二级分类图标

- Room **v9** + `MIGRATION_8_9`：`sub_categories.iconName`，常见二级名回填。
- `SubCategoryPresets.SUB_ICONS` + 新增/预置灌入；`IconMapper` 扩别名。
- 分类管理 / 记一笔二级 Chip 展示图标。

## 7. 推理耗时旁挂折叠条

- 耗时写入 `<!--SA_ELAPSED-->` 元数据，**展示在「思考过程」折叠标题旁**，不再追加回答末尾。
- 兼容旧消息末尾「—— 总耗时 …」解析。
